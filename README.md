## Adding a recipe

1. Copy `templates/recipe-template.md` into `recipes/<category>/`.
2. Name it in lowercase with hyphens, e.g. `ropa-vieja.md`.
3. Fill in the front matter and sections.
4. Add a link to it under **Recipes** above.

Categories: `mains`, `sides`, `soups-stews`, `breakfast`, `desserts`, `drinks`, `sauces-staples`.

See [AGENTS.md](AGENTS.md) for the full conventions.
